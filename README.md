# R&M Tapicería — demo independiente

Web estática HTML, CSS y JavaScript, sin dependencias de compilación. No es la web oficial.

## Cloudflare Pages
- Repositorio: ledo386/rym-tapiceria-demo
- Rama de producción: main
- Framework preset: None
- Build command: vacío
- Build output directory: .
- Root directory: vacío

Incluye cabecera sticky, navegación móvil, seis servicios, dos comparadores SVG, galería filtrable y ampliable, selector de acabados, preguntas frecuentes y preparación de un mensaje de WhatsApp. No envía datos automáticamente ni tiene servidor.

Antes de publicar una versión oficial: validar identidad comercial, teléfono/WhatsApp, horarios, catálogo, trayectoria, textos, permisos de imágenes y datos legales. La demo lleva noindex y un aviso visible; noindex no restringe el acceso público. Las imágenes de Unsplash son referencias externas (créditos en el pie), y las ilustraciones SVG son locales. Sustituir fotografías por trabajos propios autorizados. El esquema de ubicación es decorativo, no un mapa geográfico. No se han inventado fechas de fundación ni testimonios literales.

Los enlaces a WhatsApp y Maps son externos. Las tipografías de Google Fonts y fotos de Unsplash requieren conexión; hay tipografías de respaldo y SVG locales si falla una imagen.
